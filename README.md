## 📌 Overview

This project focuses on predicting whether a credit card client will default on their payment using Machine Learning techniques. The project includes complete data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and comparison.

The dataset used is the **UCI Credit Card Default Dataset**, containing customer demographics, billing history, payment history, and default information.
